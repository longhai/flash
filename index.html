Game Flash
Để thêm game: up file .swf lên cùng thư mục với trang này, rồi thêm 1 dòng vào danh sách GAMES trong file này, ví dụ:
{name:'Tên game', file:'ten-game.swf'}
Muốn có icon riêng cho game thì thêm icon:'ten-icon.png' vào dòng đó (file ảnh để cùng thư mục). Trang chơi là flash-player.html cùng thư mục.

Hoặc bấm ＋ Tải lên game để chọn file .swf trên máy — game được lưu vào máy (kiểu như launcher NES lưu ROM) và hiện ngay trong thư viện, lần sau bấm là chơi, không cần up lên web.
